## Task 2.3 — ExperienceSection: RESP-01 + A11Y-04

**Type:** implementation
**File:** `components/ExperienceSection.tsx`

**Action:**

Two inline grids in ExperienceSection need to be converted to Tailwind className props, and the current-role pulse dot needs `className="ms-pulse-anim"`.

**Change 1 — Education + Community row grid (lines 234–242):**

This `<div>` currently uses:
```tsx
style={{
  display: "grid",
  gridTemplateColumns: "1fr 1fr",
  gap: 64,
  marginTop: 64,
  paddingTop: 48,
  borderTop: "1px solid var(--ms-border)",
  alignItems: "start",
}}
```

Replace `display: "grid"` and `gridTemplateColumns: "1fr 1fr"` with a Tailwind className. Keep the remaining style props that have no Tailwind equivalent:

```tsx
className="grid grid-cols-1 ms:grid-cols-2"
style={{
  gap: 64,
  marginTop: 64,
  paddingTop: 48,
  borderTop: "1px solid var(--ms-border)",
  alignItems: "start",
}}
```

**Change 2 — Timeline entry meta + description grid (lines 144–151):**

Each timeline entry has an inner `<div>` with:
```tsx
style={{
  display: "grid",
  gridTemplateColumns: "220px 1fr",
  gap: 40,
  alignItems: "start",
}}
```

Replace `display: "grid"` and `gridTemplateColumns: "220px 1fr"` with a Tailwind className:

```tsx
className="grid grid-cols-1 ms:grid-cols-[220px_1fr]"
style={{
  gap: 40,
  alignItems: "start",
}}
```

On mobile the meta block (company, role, dates) will stack above the description paragraph. On >= 760px the fixed 220px meta column returns.

**Change 3 — Current-role dot: add ms-pulse-anim (lines 112–126):**

The `current === true` branch renders an orange pulsing dot with inline `animation: "ms-pulse var(--anim-pulse) infinite"`. This inline style is not caught by the existing CSS reduced-motion rule. Add `className="ms-pulse-anim"` to hook it into the `!important` rule added in 06-01.

The dot `<div>` currently reads (line 113–125):
```tsx
<div
  aria-hidden="true"
  style={{
    position: "absolute",
    left: -1,
    top: 2,
    width: 16,
    height: 16,
    borderRadius: "50%",
    background: "var(--ms-orange)",
    boxShadow: "0 0 0 4px var(--ms-orange-dim)",
    animation: "ms-pulse var(--anim-pulse) infinite",
  }}
/>
```

Add `className="ms-pulse-anim"` to this element:
```tsx
<div
  aria-hidden="true"
  className="ms-pulse-anim"
  style={{
    position: "absolute",
    left: -1,
    top: 2,
    width: 16,
    height: 16,
    borderRadius: "50%",
    background: "var(--ms-orange)",
    boxShadow: "0 0 0 4px var(--ms-orange-dim)",
    animation: "ms-pulse var(--anim-pulse) infinite",
  }}
/>
```

## Task 2.4 — SiteHeader: remove nav overflow clipping

**Type:** implementation
**File:** `components/SiteHeader.tsx`

**Action:**

The `<nav>` element at lines 88–96 currently has `overflow: "hidden"` in its inline style. At narrow viewports the nav links wrap due to `flexWrap: "wrap"` (also present), but `overflow: "hidden"` clips any wrapped links that would fall outside the container's initial height, making them invisible.

The requirements do not specify a hamburger menu, so the fix is minimal: remove `overflow: "hidden"` from the nav's style prop so wrapped links remain visible.

Current nav style:
```tsx
style={{
  display: "flex",
  alignItems: "center",
  gap: 32,
  flexWrap: "wrap",
  overflow: "hidden",
}}
```

Updated nav style (remove `overflow: "hidden"`):
```tsx
style={{
  display: "flex",
  alignItems: "center",
  gap: 32,
  flexWrap: "wrap",
}}
```

No other changes to SiteHeader.

**Verify:**
- [ ] `grep -n "overflow" components/SiteHeader.tsx` returns no results (the `overflow: "hidden"` line is gone)
- [ ] `npm run build` exits 0

**Acceptance criteria:**
- `overflow: "hidden"` is removed from the nav element's inline style
- All other nav styles (`display: "flex"`, `alignItems: "center"`, `gap: 32`, `flexWrap: "wrap"`) remain unchanged
