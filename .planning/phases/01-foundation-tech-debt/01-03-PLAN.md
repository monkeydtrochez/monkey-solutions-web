**Step 1: Create `components/ThemeToggle.tsx`** as a new file:

```tsx
"use client"

export function ThemeToggle() {
  function toggle() {
    const current = document.documentElement.dataset.theme || 'dark'
    const next = current === 'dark' ? 'light' : 'dark'
    document.documentElement.dataset.theme = next
    try { localStorage.setItem('ms_theme', next) } catch {}
  }

  return (
    <button
      onClick={toggle}
      aria-label="Toggle theme"
      style={{ position: 'fixed', top: '1rem', right: '1rem', zIndex: 9999, padding: '0.5rem 1rem', cursor: 'pointer' }}
    >
      Toggle theme
    </button>
  )
}
```

Key constraints per D-07:
- No `useState` — direct DOM manipulation only
- No React context — reads/writes `document.documentElement.dataset.theme` directly
- Writes to `localStorage` key `ms_theme` (matching the inline script in layout.tsx)
- `"use client"` directive as first line, before any imports
- `aria-label="Toggle theme"` is required (accessibility)
- Inline style for positioning is acceptable for this temporary Phase 1 button — exact styling does not matter, only that it is visible and clickable

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → inline script | Client-only; attacker could set ms_theme to arbitrary value |
| ThemeToggle → document.documentElement | Client-side DOM write; no server data involved |
| next/font/google → build time | Font files fetched by Next.js at build, served from own origin — no runtime external requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | Inline script (localStorage read) | accept | The only values that matter are "dark" and "light"; any other value in localStorage falls back to "dark" via `t\|\|"dark"` — attacker cannot inject harmful values |
| T-03-02 | Information Disclosure | next/font/google | accept | Font files are public assets; no credentials or PII involved. Build-time fetch is from Google Fonts CDN; served at runtime from /_next/static/media/ |
| T-03-03 | Spoofing | ThemeToggle DOM write | accept | Only affects CSS class on <html>; no authentication or authorization implications; no PII |
| T-03-04 | Denial of Service | localStorage access in inline script | mitigate | try/catch around localStorage.getItem prevents private-browsing SecurityError from breaking page load |
</threat_model>
