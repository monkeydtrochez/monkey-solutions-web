| `--section-py-contact` | 140px | Contact section vertical padding |

Exceptions: This scale is sourced directly from `design_handoff_monkey_solutions/README.md`
spacing tables per CONTEXT.md D-04/D-05. The design handoff uses a fine-grained typographic
scale with 2px increments for optical balance at small sizes (6px `--space-2`, 10px `--space-4`,
14px `--space-6`, 18px `--space-8`). Rounding to the nearest multiple of 4 would break the
visual rhythm specified in the handoff. All values serve named layout purposes as documented
in the Usage column. Values outside the standard set (12, 20, 28, 36, 40, 56, 72, 80, 96, 120)
are multiples of 2 and sourced from the same design handoff — they represent intentional
mid-points in the layout system.

## Typography

Source: RESEARCH.md — design handoff type scale + D-08 font decisions.

All type tokens are defined as CSS custom properties in `globals.css :root` for
immediate use in future phases. Phase 1 activates Inter as the body font; the
full scale is available for phases 2–5.

| Token | Value | Role |
|-------|-------|------|
| `--text-hero` | `clamp(48px, 8vw, 112px)` | Hero H1 |
| `--text-h2` | `clamp(36px, 5vw, 88px)` | Section H2 |
| `--text-h3` | `26px` | Card H3 |
| `--text-body-lg` | `17px` | Lead paragraphs |
| `--text-body` | `16px` | Body text |
| `--text-small` | `14px` | Small body |
| `--text-mono` | `12px` | Terminal mono, JetBrains Mono body |
| `--text-label` | `11px` | Mono kicker labels (uppercase) |
| `--lh-tight` | `0.92` | Hero headline line height |
| `--lh-body` | `1.6` | Body paragraphs |
| `--tracking-tight` | `-0.045em` | Large headlines |

Exception: Full type scale pre-declared per CONTEXT.md D-04 — Phase 1 activates only
`--text-body` (16px), `--text-small` (14px), `--text-mono` (12px), and `--text-label`
(11px) for the ThemeToggle button; remaining sizes (`--text-hero`, `--text-h2`,
`--text-h3`, `--text-body-lg`) are token-layer-only definitions for phases 2–5, not
rendered in Phase 1.

Font weights used across the full design:

| Family | Weights | CSS variable |
|--------|---------|--------------|
| Inter | 300 (light), 400 (regular), 500 (medium), 600 (semibold), 700 (bold), 800 (extrabold) | `--font-sans` |
| JetBrains Mono | 400, 500, 600, 700 | `--font-mono` |
| Fraunces | 300, 400, 500 — italic only | `--font-display` |

Exception: Font weights are declared as variable font ranges, not fixed weight installs.
Inter, JetBrains Mono, and Fraunces all use `weight: 'variable'` in `next/font/google`
per RESEARCH.md — the full weight range is a single variable font file. Phase 1 actively
renders only Inter 400 (body text) and Inter 700 (ThemeToggle label) — the full range is
pre-declared for phases 2–5.

Phase 1 declaration requirements:

- Inter: `weight: 'variable'`, `style: 'normal'`, `subsets: ['latin']`, `display: 'swap'`, `variable: '--font-sans'`
- JetBrains Mono: `weight: 'variable'`, `style: 'normal'`, `subsets: ['latin']`, `display: 'swap'`, `variable: '--font-mono'`
- Fraunces: `weight: 'variable'`, `style: ['italic']`, `subsets: ['latin']`, `display: 'swap'`, `variable: '--font-display'`

Body defaults applied in Phase 1 via `globals.css`:

```css
body {
  font-family: var(--font-sans), system-ui, sans-serif;
  -webkit-font-smoothing: antialiased;
  font-feature-settings: "ss01", "ss02", "cv11";
}
```

`tailwind.config.ts` must extend `fontFamily` to map Tailwind utilities:

```ts
fontFamily: {
  sans:    ['var(--font-sans)', 'system-ui', 'sans-serif'],
  mono:    ['var(--font-mono)', 'monospace'],
  display: ['var(--font-display)', 'serif'],
}
```

### Important: `--border` / `--input` rgba Compatibility

`tailwind.config.ts` currently wraps `--border` as `"hsl(var(--border))"`. The
new `--border` values are raw `rgba()` strings — incompatible with `hsl()`.

Required fix: change `tailwind.config.ts` entries for `border` and `input` from
`"hsl(var(--border))"` to `"var(--border)"` and `"var(--input)"` respectively.
This is the only required change to `tailwind.config.ts` for color tokens.

## Tailwind Dark Variant Override

Required in `globals.css` after `@import "tailwindcss"` and `@config`:

```css
@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *));
```

This replaces the `.dark` class strategy. All existing `dark:` utility classes
in shadcn components continue working automatically.

`tailwind.config.ts`: remove or comment out `darkMode: "class"` — it becomes a
no-op once `@custom-variant dark` is defined in CSS.

## ThemeToggle Component Contract

Source: CONTEXT.md D-06, D-07.

This component is Phase 1's only new interactive element.

| Property | Specification |
|----------|---------------|
| File | `components/ThemeToggle.tsx` |
| Directive | `"use client"` |
| State management | None — direct DOM manipulation only (no useState, no context) |
| Reads | `document.documentElement.dataset.theme` |
| Writes | `document.documentElement.dataset.theme` + `localStorage.setItem("ms_theme", next)` |
| localStorage key | `ms_theme` |
| Toggle values | `"dark"` ↔ `"light"` |
| Fallback | Default to `"dark"` when no value in localStorage |
| Phase 1 label | "Toggle theme" (plain text — Phase 2 adds icon styling) |
| aria-label | `aria-label="Toggle theme"` |
| Phase 1 placement | Temporary: `<ThemeToggle />` in `app/page.tsx` for verification |
| Phase 2 action | Remove from `app/page.tsx`, integrate into header |

No visual styling requirements for Phase 1's temp button — any visible, clickable
button suffices for verification.

## No-FOUC Inline Script Contract

Source: CONTEXT.md D-06, RESEARCH.md Pattern 1.

| Property | Specification |
|----------|---------------|
| Placement | `<head>` in `app/layout.tsx` — before all other tags |
| Execution | Synchronous IIFE — no `async`, no `defer` |
| Attribute target | `document.documentElement.setAttribute("data-theme", ...)` |
| Fallback | `"dark"` when localStorage is empty or throws |
| SSR default | `<html lang="en" data-theme="dark" suppressHydrationWarning>` |
| `suppressHydrationWarning` | On `<html>` element only |

Script (minified, no whitespace):
```js
(function(){try{var t=localStorage.getItem("ms_theme");document.documentElement.setAttribute("data-theme",t||"dark")}catch(e){}})()
```
