> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

### Header Background Detail

The header does NOT use a design token for its background — it is a hardcoded rgba
with transparency for the blur effect:

| Theme | Background | Blur |
|-------|-----------|------|
| dark | `rgba(13,11,9,0.78)` | `backdrop-filter: blur(12px)` |
| light | `rgba(247,244,238,0.82)` | `backdrop-filter: blur(12px)` |

Header border-bottom: `1px solid var(--ms-border)`.

### Hero Background FX (decorative, aria-hidden)

Two absolutely-positioned decorative layers:

1. Grid lines: `repeating-linear-gradient` in `--ms-border` color, 64×64px tile, masked by
   `radial-gradient(ellipse at 70% 40%, #000 20%, transparent 70%)`. Opacity 0.5.

2. Orange glow blob: `radial-gradient(circle, rgba(255,107,26,0.13) 0%, transparent 60%)`.
   Size 520×520px. Position `right: -10%; top: 10%`. Use `var(--ms-orange)` at 0x13 alpha
   (dark) / `var(--ms-orange)` at 0x10 alpha (light, i.e. `${orange}10`).
   Exact value from handoff: `${T.orange}22` — which in the dark theme = `#ff6b1a22`
   (hex alpha). Implement as: `background: radial-gradient(circle, color-mix(in srgb, var(--ms-orange) 13%, transparent) 0%, transparent 60%)`.

## Animation Contracts (Phase 2 active animations)

All animation keyframes and durations are pre-declared in Phase 1. Phase 2 activates
two of them for the first time in rendered components:

| Animation | Keyframe | Used by | Reduced-motion |
|-----------|----------|---------|----------------|
| `ms-pulse` | `scale 1→2.6, opacity 0.5→0, 2.2s ease-out infinite` | Status dot (hero + hire CTA) | `animation: none` |
| `ms-cursor` | `opacity 1→0, step-end, 1.1s infinite` | Terminal cursor `_` | `animation: none` |

Reduced-motion rule is already declared in `globals.css` from Phase 1:
```css
@media (prefers-reduced-motion: reduce) {
  .animate-pulse, [class*="ms-cursor"] { animation: none; }
}
```

Executor must ensure the cursor span's class name contains "ms-cursor" OR add a
matching class/keyframe name so the reduced-motion rule fires correctly.

Hover transitions (no keyframes — CSS `transition` only):
- All buttons: `transition: background-color 0.2s` (via `--anim-hover`)
- Theme toggle buttons: `transition: background-color 0.2s, color 0.2s`

## Accessibility Contract

| Element | Requirement |
|---------|-------------|
| Logo link `<a href="#top">` | No aria-label needed — contains visible text "monkey/solutions" |
| Nav links `<a href="#about">` etc. | No aria-label needed — number + label are visible text |
