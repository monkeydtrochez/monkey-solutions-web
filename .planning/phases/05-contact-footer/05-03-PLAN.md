<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GlobalContext.profile → Footer DOM | CMS-managed data (availabilityStatus, orgNumber, readCvUrl) rendered as read-only text |
| External link hrefs → User browser | linkedInUrl, githubUrl, readCvUrl are URLs from Sanity; rendered in <a> elements |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-09 | Information Disclosure | orgNumber rendered in DOM | accept | Organisation number is legally public information in Sweden (bolagsverket). Intentionally displayed per D-09 and UI-SPEC. Not sensitive. |
| T-05-10 | Tampering | External URLs (linkedInUrl, githubUrl, readCvUrl) from Sanity CMS | accept | Sanity Studio access is restricted to authenticated editors (Daniel only). URLs are validated as url type in the Sanity schema. `rel="noopener noreferrer"` prevents opener-based tab navigation attacks. |
| T-05-11 | Information Disclosure | readCvUrl null guard | mitigate | Conditional render `{profile?.readCvUrl && ...}` prevents `href="undefined"` or `href="null"` in DOM. Pitfall 5 in RESEARCH.md. Verified by grep gate in acceptance criteria. |
</threat_model>
