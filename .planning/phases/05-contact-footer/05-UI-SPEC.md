## Typography

| Tier | Canonical Size | Family | Weight | Line Height | Usage |
|------|---------------|--------|--------|-------------|-------|
| Display | `clamp(48px, 7vw, 108px)` primary; `clamp(80px, 16vw, 240px)` wordmark sub-variant | Inter (+ Fraunces italic accent) | 800 (see weight exceptions below) | `0.9` (contact H2) / `0.85` (wordmark) | Contact H2 "Let's build something."; footer giant wordmark MONKEY/solutions. |

- Regular — 400 (body text across all typefaces)

- Mono 600/700 — reserved for terminal-style code elements (kicker numbers, "◉ RESUME" label, submit button, language badge text) only

## Component Anatomy

### ContactSection (`"use client"`)

**Section wrapper:**
- `<section id="contact">`
- Padding: `var(--section-py-contact) var(--page-px) 100px`
- Background: `var(--ms-bg)`
- Overflow: hidden, position relative
- BG glow: absolute element `left: -10%, top: 5%`, 600×600px circle, `radial-gradient(var(--ms-orange-dim) 0%, transparent 60%)`

**Inner max-width wrapper:** `max-width: var(--content-max)`, `margin: 0 auto`

**Two-column grid:** `display: grid`, `grid-template-columns: 1fr 1.1fr`, `gap: 80px`

**Left column:**
1. Kicker: `07 CONTACT` (established `<Kicker>` pattern — mono 12/600 orangeText + 28×1 hairline + uppercase mono 12 fgSoft)
2. H2: `clamp(48px, 7vw, 108px)`, `line-height: 0.9`, Inter 800 fg — two lines: "Let's" then "<em>build</em> something." — `<em>` is Fraunces italic 300 `var(--ms-orange-text)`
3. Lede `<p>`: Inter 17 line-height 1.6 fgSoft, `max-width: 460px`
4. Direct links list: `flex`, `flex-direction: column`, `gap: 16px`, `font-family: var(--font-mono)`, `font-size: 13px`
   - Each `<a>` row: flex align-center, small leading icon (11px fgFaint) + address text (borderBottom 1px borderStrong) + ↗ (orangeText, ml auto)
   - Items: email (mailto:), LinkedIn, GitHub — values from `GlobalContext.profile`
5. Resume download card (marginTop 56px):
   - `padding: 24px`, border `1px var(--ms-border-strong)`, `border-radius: var(--radius-xl)` (10px), bg `var(--ms-surface)`
   - Header row: `◉ RESUME` (mono 11/700 orangeText) + flex-1 hairline + "pdf · v2026.04" (mono 10 fgFaint)
   - Description `<p>`: Inter 14 fgSoft line-height 1.5 — "Prefer to read the traditional way? Grab a PDF copy — available in English and Swedish."
   - Two `<a download>` buttons: `display: grid`, `grid-template-columns: 1fr 1fr`, `gap: 8px`
     - Each: `padding: 16px`, border `1px var(--ms-border-strong)`, `border-radius: var(--radius-lg)` (8px), bg `var(--ms-bg)`, flex gap 16 align-center
     - Hover: borderColor → `var(--ms-orange)`, bg → `var(--ms-mist)`, transition `var(--anim-hover)` (0.2s)
     - Language badge: 36×36px, border `1px var(--ms-orange)`, color `var(--ms-orange-text)`, mono 12/700 — "EN" or "SV"
     - Middle: Inter 14/600 fg (language name) over mono 10 fgFaint (filename)
     - Right: ↓ (orangeText)
     - EN: `href="/resume_en.pdf" download`, "English" / "resume_en.pdf"
     - SV: `href="/resume_sv.pdf" download`, "Svenska" / "resume_sv.pdf"

**Right column — Form card:**
- `padding: 40px`, border `1px var(--ms-border-strong)`, `border-radius: var(--radius-2xl)` (12px), bg `var(--ms-surface)`, position relative
- Card header: 3 traffic-light dots (aria-hidden; `--color-tl-red`, `--color-tl-yellow`, `--color-tl-green`) + "./new_project.sh" (mono 11 fgFaint, ml 8), marginBottom 28px
- **4 fields** (name, email, budget, project):
  - Field wrapper: `margin-bottom: 24px`
  - Label: mono 10, uppercase, `letter-spacing: 1px`, fgFaint, `margin-bottom: 8px` — prefix `> ` (e.g. `> name`)
  - Inputs (name, email, budget): `width: 100%`, `padding: 8px 0`, `border: none`, `border-bottom: 1.5px solid var(--ms-border-strong)`, transparent bg, Inter 16 fg, outline none
  - Textarea (project): same border-bottom style, `rows: 4`
  - Focus: `border-bottom-color → var(--ms-orange)` (via `onFocus`/`onBlur` handlers)
  - Placeholders: "Your name" / "you@company.com" / "€10k · €50k · let's talk" / "What are we building? Timeline, constraints, the interesting bits..."
- **Submit `<button>`:**
  - `type="submit"`, `aria-live="polite"`, `disabled` when `sending`
  - Width 100%, padding `16px 20px`, no border, mono 13/700, letter-spacing 0.5px, `border-radius: var(--radius-lg)` (8px)
  - Default state: bg `var(--ms-orange)`, color `var(--ms-bg)` (dark: #0d0b09 / light: #ffffff)
  - Default label: "$ send_message →"
  - Sending state: `cursor: not-allowed`, bg unchanged
  - Success state: bg `#27c93f`, label "✓ Message sent — talk soon!", reverts after 3.5s
  - Transition: `background 0.2s`
- Below button: mono 10 fgFaint centered — "Or email directly — whatever you prefer."
- Inline error: mono 11 fgFaint / destructive, below button, only visible on fetch failure — "Something went wrong — try again."

## Interaction States

### Form Field Focus
- Input/textarea bottom border transitions from `var(--ms-border-strong)` to `var(--ms-orange)` on `:focus`.
- Implemented via `onFocus`/`onBlur` inline handlers (matches existing codebase style).
- No outline; border-bottom is the sole focus indicator for these inputs.
- Submit button uses `:focus-visible` orange ring: `outline: 2px solid var(--ms-orange); outline-offset: 2px` (Phase 6 a11y — note in code as TODO).

### Form Submission States
| State | Button bg | Button label | Notes |
|-------|-----------|--------------|-------|
| Default | `var(--ms-orange)` | "$ send_message →" | Cursor pointer |
| Sending | `var(--ms-orange)` | "$ send_message →" | `disabled`, cursor not-allowed |
| Success (3.5s) | `#27c93f` | "✓ Message sent — talk soon!" | `aria-live="polite"` announces change |
| Error | `var(--ms-orange)` | "$ send_message →" | Error message "Something went wrong — try again." appears below button |

### Resume Download Button Hover
- Border: `var(--ms-border-strong)` → `var(--ms-orange)`, transition `0.2s`
- Background: transparent → `var(--ms-mist)`, transition `0.2s`

### Footer Pulsing Dot
- Pulsing ring: `ms-pulse` animation at `var(--anim-pulse)` = 2.2s, infinite.
- Stops under `@media (prefers-reduced-motion: reduce)` (already in globals.css).
