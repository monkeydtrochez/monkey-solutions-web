# Phase 3 — UI Design Contract

> Visual and interaction contract for Phase 3: About + Work.
> Generated by gsd-ui-researcher.
>
> Phase 3 delivers two content sections: (1) a two-column About section with editorial H2,
> body copy, portrait placeholder with sticker badge, and facts row; (2) a Work section
> with a category filter segmented control and an expandable project accordion with metrics
> card and screenshot placeholder. All design tokens, fonts, and layout patterns are
> pre-established by Phases 1–2 — this contract maps them to Phase 3 elements.

## Interaction Contract

| Filter — "all" | Click | Show all 6 projects; `all` pill becomes active (orange bg) |
| Filter — "web" | Click | Show projects where `kind` matches `/commerce\|web\|booking/i`; close any open row not in filtered set |
| Filter — "ios" | Click | Show projects where `kind` matches `/iOS/`; close any open row not in filtered set |
| Filter — "saas" | Click | Show projects where `kind` matches `/SaaS/i`; close any open row not in filtered set |
| Accordion — click closed row | Click | Open that row; close previously open row (one open at a time). Apply `ms-fadein` to expanded panel. Background becomes `--ms-mist`. Arrow rotates 90deg + colors orangeText. |

| Default open state | Mount | First project in sorted list (sortIndex 1) is open. `aria-expanded="true"`. |
| Filter changes | Filter click | If currently open project is not in new filtered set, collapse it (no open row). If it is in new set, keep it open. |
| "Case study ↗" | Click | `<a href="#">` — placeholder; links to nothing until real case study pages exist. |
| "Ask for the extended portfolio →" | Click | `<a href="#contact">` — smooth scroll to contact section. |

## Accordion Behavior — State Contract

`WorkSection` is a client component with two pieces of state:

```typescript
const [filter, setFilter] = useState<'all' | 'web' | 'ios' | 'saas'>('all');
const [openId, setOpenId] = useState<string | null>(firstProjectId);
// firstProjectId = projects sorted by sortIndex, take [0].id
```

Filter change side effect: if `openId` is not in the newly filtered list, reset to `null`
(no open row). If it is in the filtered list, keep it open.

Toggle handler:
```typescript
// click row with id p._id:
setOpenId(prev => prev === p._id ? null : p._id);
```

Filter regex (authoritative — copy verbatim from hifi):
```typescript
const shown = projects.filter(p => {
  if (filter === 'all') return true;
  if (filter === 'web') return /commerce|web|booking/i.test(p.kind ?? '');
  if (filter === 'ios') return /iOS/.test(p.kind ?? '');
  if (filter === 'saas') return /SaaS/i.test(p.kind ?? '');
  return true;
});
```
